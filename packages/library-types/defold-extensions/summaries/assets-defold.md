## What it ships

Official Defold logo images in PNG and SVG: the plain logo, the logo with
"Defold" text, and the "Made with Defold" logo. Each comes in several color
variants and widths of 64, 128, 160 and 320 pixels plus a high-resolution
original.

## Using it

Add the repository zip archive to the `[project]` dependencies in
`game.project`; the images are then available under `/assets-defold`, for
example on a splash screen. Use of other logo versions requires permission
from the Defold Foundation.
